# DevSquad 运行回放

在前端目录运行 `npm ci` 和 `npm run dev`，再打开终端给出的本机地址。`npm run build` 生成静态构建。

页面自带一批合成仓库的真实模型评估记录。可按用例名、仓库和失败结果筛选，切换试跑，查看模型、工具与审批事件。代码变更视图标记增删行号，支持按文件查看和下载原始补丁。

评估脚本导出的 JSON 可以通过文件选择、拖放或粘贴载入。文件在浏览器本地解析，也可以随时切回内置样例。

## 实时任务

在 Linux 或 WSL 中安装后端，在同一个环境配置 `DEVSQUAD_TOKEN` 和 `DEEPSEEK_API_KEY`。构建前端后，从仓库根目录启动本机服务。

```bash
devsquad serve --web-root frontend/dist
```

打开 `http://127.0.0.1:8765`，切到「实时任务」，输入 `DEVSQUAD_TOKEN` 的值。它为浏览器提供本机访问权限，模型密钥仍由服务端读取。选择你信任的 Git 仓库，填写后端所见的绝对路径，例如 `/mnt/d/my-repo`。Windows 浏览器访问 WSL 服务需要本机回环转发。

需求下方最多添加 3 个附件。支持选择文件、拖入附件区，或在附件区粘贴截图和文字。可添加 UTF-8 代码、Markdown、日志、可提取文字的 PDF 和单帧 PNG/JPEG。每个文件最多 256 KiB，文本和 PDF 提取结果最多 6 KiB，PDF 最多 20 页。纯扫描 PDF 可以先截图。

提交任务时，后端将附件作为本轮参考发送给 DeepSeek。PDF 在本机提取正文，截图去除文件元数据后发送。附件原件与正文没有单独写入任务数据库或工作区。请只添加允许发送给模型的内容。

运行过程通过 SSE 更新。每个写入或命令请求都需要逐次确认，超时 120 秒按拒绝处理。刷新网页后可以重新连接本机服务，恢复查看该服务进程的最近一次运行。服务重启后可用 CLI 查询已落库的轨迹。
